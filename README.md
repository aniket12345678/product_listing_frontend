# Product Listing Frontend

This is the frontend repository for the Product Listing application.

## Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites

- Node.js (latest LTS recommended)
- npm (comes with Node.js)

### Installation

1. **Clone the Repository**

   Open the Windows Shell and run:
   ```sh
   git clone https://github.com/aniket12345678/product_listing_frontend.git
   ```

2. **Navigate to the Project Directory**
   ```sh
   cd product_listing_frontend
   ```

3. **Install Dependencies**
   ```sh
   npm install
   ```

4. **Start the Development Server**
   ```sh
   npm run dev
   ```

### Project Structure

The repository follows a standard React project structure.

```
product_listing_frontend/
│-- src/
│   ├── components/       # Reusable components
│   ├── pages/            # Page components
│   ├── routes/           # Routing component
│   ├── common/           # Common methods
│   ├── api.js            # API handling
│   ├── slice.js          # Slices file
│   ├── assets/           # Static assets
│   ├── App.js            # Main application file
│-- public/               # Public assets
│-- package.json          # Project dependencies
│-- .gitignore            # Git ignore file
│-- README.md             # Project documentation
```
